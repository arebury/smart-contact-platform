Checkbox

<sc-tri-state-checkbox> es el checkbox de facto en SC. Soporta los 2 estados binarios ('none' / 'all') + un tercero 'some' (indeterminate, extensión SC) para headers de tabla con bulk-select mixto.

1 · Basic (binary)

Estado controlado externamente. El cycle output emite el siguiente boolean al click.

2 · Sizes (sm / md / lg)

Tres tamaños del Figma — sm 14×14, md 17.5×17.5 (default), lg 21×21. El icono y el label escalan proporcionalmente.

Small (14px) Medium / default (17.5px) Large (21px)

3 · Filled (background slate-50)

Variant del Figma Filled=True (node 5801:52774): bg slate-50 cuando unchecked. Útil cuando el checkbox vive sobre un canvas blanco y necesita destacar.

Filled checkbox

4 · Disabled

El componente se vuelve no-interactivo. Opacity 60% (token global disabled/opacity).

Opción no disponible (off) Opción no disponible (on)

5 · Tri-state (SC extension)

Patrón "select all" del header de tabla: estado 'some' = marcado parcial. Mismo bg que 'all' pero con una barra horizontal en lugar de ✓. Cycle behavior: none → todos marcados; some → todos limpios; all → todos limpios.

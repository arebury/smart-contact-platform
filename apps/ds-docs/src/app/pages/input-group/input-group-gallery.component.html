Input group

<sc-input-group> envuelve <p-inputgroup> para componer un input con addons left/right: texto, icono, botón, checkbox o radio. PrimeNG hace el border-merge entre el input y los addons (los addons absorben el borde compartido); el wrapper SCDS solo añade size y fluid para combinar con el resto del DS. Distinto de sc-search, que es para icon overlay decorativo sin borde merge.

1 · Addon de texto

El caso clásico: prefijo o sufijo de unidad sobre un input numérico o un input de URL. Los addons absorben el borde compartido — el resultado lee como una pieza única.

Component

Toast

Notificación efímera anclada abajo a la derecha. Basada en <p-toast> de PrimeNG con un pTemplate="message" override + tokens --sc-toast-*. Pulsa los botones de cada sección para ver el toast en vivo.

1 · Severities

5 tonos: success / info / warn / error / secondary (overload SC → violeta para "neutral notices" tipo borrador creado).

2 · Con botón "Deshacer" (SC extension)

Patrón undo: data.undoEntryId en MessageService.add() añade un botón de acción al toast. Figma no modela este slot — es extensión SC.

3 · Sticky (no auto-dismiss)

sticky: true evita el auto-dismiss. Usado para acciones de fondo (sincronización, carga larga). El usuario debe cerrarlo con la X.

4 · Texto largo

El toast tiene width: 350px fijo (Figma) — textos largos hacen wrap natural dentro de ese ancho.

5 · Limpiar todos

MessageService.clear() sin argumentos cierra todos los toasts activos.

Buttons gallery

Every <p-button> variant rendered with the AED preset applied. Colors and shapes come from sc-preset.ts; this page is a passive viewer with no styles of its own beyond layout. Reach it at /dev/buttons — not linked from the sidebar.

1 · Filled (default)

8 severities. Background = brand color, white text. Used for primary CTAs and explicit status actions.

@for (sev of severities; track sev) { }

2 · Outlined

Transparent background, colored border + text. Lower visual weight than filled — good for secondary actions inside dense layouts.

@for (sev of severities; track sev) { }

3 · Text

No chrome at all. Hover paints a subtle tinted background. Useful for low-emphasis actions like "Cancelar" inside a footer.

@for (sev of severities; track sev) { }

4 · Raised (shadow)

Filled buttons with a drop shadow. Heavy treatment — use sparingly. Disabled by default in the AED brand voice ("calm · dense · operational") but available.

@for (sev of severities; track sev) { }

5 · Rounded (pill)

Pill shape via [rounded]="true". Big departure from AED's standard 6px radii; kept available because PrimeNG ships it.

@for (sev of severities; track sev) { }

6 · Sizes

Three sizes via [size]. AED's custom .btn--sm matches PrimeNG's small at 32 px; default at ~40 px; large at ~48 px.

7 · Icon-only

Square buttons via [icon] + no label. Use a PrimeIcon class string. AED currently has its own .btn--icon at 32×32; PrimeNG default is ~40×40.

@for (sev of severities; track sev) { }

8 · Icon + label

Icon-with-text. PrimeNG positions the icon left by default; iconPos="right" flips it.

9 · Loading

Click any button below to flip the loading flag. While loading, the icon swaps to a spinner and the button becomes uninteractive — built into PrimeNG, no AED CSS required.

10 · Disabled

Disabled via [disabled]="true". PrimeNG drops opacity and disables pointer events. Works across all severities and variants.

@for (sev of severities; track sev) { }

11 · Link

[link]="true". Renders as a button-styled-as-link (still semantically a button element). Use a real <a> for navigation; this is for inline actions that look like links.

Component

Section Card

<sc-section-card> agrupa campos dentro de un form largo. Bordered, con header opcional (icon + título + hint). Soporta modo collapsible para "advanced settings" plegadas por defecto. Patrón canónico SC para forms con 3+ secciones lógicas.

1 · Basic

Card con título simple + body proyectado.

Contenido del body proyectado. Cualquier markup: campos, grids, helper text...

2 · Con hint

Hint debajo del título para contextualizar la sección.

[Toggle switches de permisos aquí]

3 · Con icono

Icon leading 16px en el header. Pasa cualquier Lucide directamente.

[Campos nombre, email, foto...]

4 · Collapsible (open default)

Header se vuelve <button> con chevron. Click para colapsar/expandir.

[Contenido avanzado — visible por defecto, clic en el header para plegar]

5 · Collapsible (closed default)

Inicialmente plegada. El usuario tiene que expandir manualmente — útil para reducir noise visual de settings menos importantes.

[Permisos avanzados ocultos por defecto]

6 · Anchor (scroll-spy)

El [anchorId] expone un id + data-section-anchor que <sc-form-section-nav> usa para scroll-spy y jump-to. La scroll-margin viene del token --sc-form-anchor-offset (default 80px) para sticky headers.

Inspecciona el DOM: el host tiene id="demo-anchor".

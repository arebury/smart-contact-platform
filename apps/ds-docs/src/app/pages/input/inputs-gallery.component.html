Component

Input

<sc-input> envuelve PrimeNG pInputText con el patrón SCDS (label + required + helper + error + iconos). Soporta [(ngModel)], Reactive Forms y signals via [(value)].

1 · Basic

Sin label, sin helper. Solo placeholder. El caso más simple.

Valor: {{ textValue() || '(vacío)' }}

2 · Label + required + helper

Patrón típico de formulario: label arriba, asterisco rojo si es required, texto de ayuda debajo.

3 · Iconos (left / right)

Iconos PrimeIcon vía [leftIcon] y [rightIcon]. El input reserva espacio para que el placeholder no se solape.

4 · Tamaños (sm / md / lg)

Tres tamaños via [size]. md es el default.

5 · Estados

Disabled, readonly, error con mensaje. El error sobreescribe al helper.

6 · [(ngModel)] binding

Compatible con FormsModule. Útil para forms no-Reactive existentes en AED.

Valor: {{ ngModelValue() }}

7 · Reactive Forms + validación

El input se pinta como inválido cuando el FormControl tiene errores Y ha sido touched.

8 · Tipos HTML

text / email / password / tel / url / search. El tipo influye en el teclado móvil y el autocomplete del navegador.

9b · Filled (background slate-50)

Variant del Figma Filled=True (node 1729:42481) — mismo chrome, background --sc-color-gray-50 (slate-50, #f8fafc) para campos que deben destacar visualmente del canvas blanco. Hover sube a slate-100.

9 · Float label

Patrón alternativo: la label flota dentro del campo y se reduce al hacer focus o cuando hay valor. Se compone con <p-floatlabel> envolviendo un pInputText — NO se usa <sc-input> aquí porque <sc-input> gestiona su propia label arriba. Tokens visuales y focus ring siguen siendo los de SCDS.

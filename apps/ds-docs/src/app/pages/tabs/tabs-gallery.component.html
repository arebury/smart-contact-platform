Component

Tabs

<p-tabs> de PrimeNG, con tokens visuales ajustados a Figma vía sc-preset.ts. SCDS NO envuelve el componente (categoría 🟣 Custom-preset, igual que <p-button>) — se usa el API nativo de PrimeNG y la chrome SC se aplica vía preset.

1 · Basic (string values)

Composición mínima: tabs + tablist con tab labels + tabpanels con tabpanel content. value como string para el binding.

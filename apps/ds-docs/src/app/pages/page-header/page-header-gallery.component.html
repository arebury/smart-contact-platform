Component

Page Header

<sc-page-header> es la cabecera estática de rutas no-entity. Banda compacta (icon chip 36×36, padding fino) con slot [page-header-actions] a la derecha para CTAs / search / filtros.

Nota S59 (modelo "todo arriba"): las list y form pages de AED + Memory ya no usan esta banda — su identidad vive en el breadcrumb del TopBar y sus acciones se proyectan al TopBar. <sc-page-header> queda para las rutas que aún la quieren (settings, repos-hub) y se conserva como red de rollback del "todo arriba".

1 · Mínimo (solo title)

El caso más simple — solo [titleKey] es required.

2 · Completo (icon + entity + title + subtitle)

Pattern canónico de list pages. Entity eyebrow uppercase + title H1 + subtitle descriptivo.

3 · Con actions (CTA primary)

Slot [page-header-actions] a la derecha para el "Nuevo X" + search + filtros.

Nueva plantilla

4 · Config page (sin icon)

Para config pages sin icon distintivo, mantener title + subtitle.

5 · Compact (title + actions)

Variant compacta para sub-pages donde el contexto ya viene del breadcrumb.

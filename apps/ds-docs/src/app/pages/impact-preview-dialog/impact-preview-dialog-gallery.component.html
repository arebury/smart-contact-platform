Impact preview dialog

<sc-impact-preview-dialog> previsualiza una operación bulk (edit / duplicate) antes de aplicar. Cada item es un chip con × hover-revealed para podarlo individualmente; el dialog se auto-cierra si se vacía completamente. Emite (confirm) con los IDs supervivientes en su orden original.

1 · Modo bulkEdit — con badge "Estado: Activo → Pausado"

El badge superior comunica el cambio que se va a aplicar. Puedes podar items individuales antes de confirmar.

2 · Modo duplicate — sin badge

Cuando NO hay badge, el dialog renderiza solo la lista de items. Pensado para "duplicar N items" donde no hay cambio de campo que comunicar.

Component

Sticky form header

<sc-sticky-form-header> es la barra superior de las pantallas Create/Edit (Users, Groups, Agents…). Muestra el título de la entidad, opcionalmente el nombre editable inline, y las acciones Save / Cancel / Delete. El botón Save lleva spinner cuando [saving]="true" y se deshabilita con [canSave]="false".

1 · Modo create

Título proviene del entityKey i18n. Aparece input para nombre arriba; Save queda deshabilitado mientras esté vacío.

Valor: "{{ newName() }}"

2 · Modo edit con rename inline

El título muestra el nombre actual. Click en el lapicito (✎) → input inline editable; Enter confirma, Esc cancela. El componente emite (nameChange) al confirmar.

Nombre guardado: "{{ savedName() }}"

3 · Estado saving (spinner)

Mientras [saving]="true", el botón Save se reemplaza por el spinner Loader2 de Lucide. El usuario sabe que el guardado está en curso sin perder el contexto.

4 · Con botón Atrás

[showBack]="true" añade un botón "Atrás" en el cluster de acciones. Default es false porque el breadcrumb de la página ya da una salida — solo activarlo en modales profundos o pantallas sin breadcrumb visible.

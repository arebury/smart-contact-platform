Empty state

<sc-empty-state> es la tarjeta centrada que aparece en list pages cuando la tabla está vacía (sin datos iniciales o tras filtrar a cero). Icono circular grande + título + descripción + CTA primaria opcional. Reserva un min-height alto para evitar saltos al alternar entre lista vacía y poblada.

1 · Lista vacía sin CTA

Estado inicial neutro — describe qué falta sin invitar a acción.

2 · Con CTA primaria

El botón aparece cuando se pasa ctaKey. Emite (cta) al click — el consumer decide qué acción dispara (abrir modal de creación, navegar a wizard, etc.).

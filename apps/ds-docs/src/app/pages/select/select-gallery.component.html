Component

Select

<sc-select> envuelve PrimeNG <p-select> con el patrón SCDS (label + required + helper + error). Acepta opciones planas (string[]) o de objeto. Soporta [(value)], [(ngModel)] y Reactive Forms.

1 · Basic (string[])

El caso más simple: opciones como array de strings. El valor seleccionado es un string.

Valor: {{ fruitValue() ?? '(sin seleccionar)' }}

2 · Opciones de objeto + optionValue

Cuando las opciones son objetos, [optionLabel] indica qué propiedad mostrar (default 'label') y [optionValue] qué propiedad bindear. Aquí guardamos solo el código de ciudad.

Código: {{ cityCode() ?? '(ninguno)' }}

3 · Bindear objeto completo

Si omites optionValue, el binding guarda el objeto entero. Útil si necesitas la región / metadata además del valor.

Objeto: {{ cityFull() ? cityFull()!.label + ' (' + cityFull()!.region + ')' : '(ninguno)' }}

4 · Tamaños (sm / md / lg)

Mismas alturas que <sc-inputtext>. md es el default.

5 · Estados / extras

Disabled, "×" para limpiar, y filtro de búsqueda dentro del dropdown.

5b · Filled (background slate-50)

Variant del Figma Filled=True (node 6195:7785) — bg --sc-color-gray-50. Hover sube a slate-100. Útil para campos que destacan del canvas blanco.

6 · Error

El error sobreescribe al helper y pinta el borde rojo.

7 · [(ngModel)] binding

Compatible con FormsModule.

Valor: {{ ngModelValue() ?? '(ninguno)' }}

8 · Reactive Forms + validación

El select se pinta como inválido cuando el FormControl tiene errores Y ha sido touched.

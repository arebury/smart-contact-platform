Inline rename cell

<sc-inline-rename-cell> es la cell editable in-place. Usada después de un "duplicar" para renombrar el borrador sin router round-trip. Autofocus + select-all al montar; Enter o ✓ → (commit); Esc o × → (cancelled). Sizing matchea exactamente la cell de reposo — la tabla no shiftea al entrar/salir de edición.

Prueba: cambia el texto y pulsa Enter (commit) o Esc (cancel). Después dale a "Reiniciar" para repetir.

Bulk edit menu

<sc-bulk-edit-menu> es el editor inline "Cambiar [campo] a [valor] Aplicar" que vive dentro de la bulk-action-bar. El caller pasa los campos y sus opciones; el componente orquesta los pickers y emite un único (commit) al pulsar Aplicar. NO incluye el dialog de impacto — el caller pipea el commit al impact-preview-dialog si quiere previsualización.

1 · 3 campos editables (Estado / Prioridad / Tipo)

Cambia el primer dropdown → el segundo dropdown se resetea al primer valor del nuevo campo (cascada — el value previo puede no ser válido para el nuevo field).

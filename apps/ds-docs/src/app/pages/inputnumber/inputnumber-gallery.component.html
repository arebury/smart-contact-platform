Component

Input number

<sc-inputnumber> envuelve un <input type="number"> nativo con el patrón SCDS (label + required + helper + error + suffix unidad). Emite number | null y soporta [(value)], [(ngModel)] y Reactive Forms.

1 · Basic

Sin label, sin helper. Solo placeholder. Texto right-aligned por convención numérica.

Valor: {{ counterValue() ?? '(null)' }} · tipo: {{ counterValue() === null ? 'null' : typeof counterValue() }}

2 · Label + helper + min/max

Patrón de formulario clásico. min y max se pasan al input nativo y al validador HTML.

3 · Suffix (unidad)

La unidad ("s", "min", "%", "agentes") va dentro del campo, alineada a la derecha. No es seleccionable.

Pausa: {{ secondsValue() ?? '(null)' }} s · Umbral: {{ percentValue() ?? '(null)' }} %

4 · Tamaños (sm / md / lg)

Mismas alturas que <sc-inputtext>. md es el default.

5 · Estados

Disabled, readonly, error con mensaje. El error sobreescribe al helper.

6 · [(ngModel)] binding

Compatible con FormsModule. Útil para forms no-Reactive existentes en AED.

Valor: {{ ngModelValue() ?? '(null)' }}

7 · Reactive Forms + validación

El input se pinta como inválido cuando el FormControl tiene errores Y ha sido touched. Aquí: required + min(1) + max(50).

8 · Step (incrementos)

step controla el incremento al usar las flechas del teclado (↑/↓). Por defecto es 1. Útil para porcentajes step="5" o décimas step="0.1".

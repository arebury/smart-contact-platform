Component

Bulk action bar

<sc-bulk-action-bar> es la barra inferior fixed que aparece cuando se seleccionan items en una tabla. Muestra "N entidad seleccionada/s" + botón vaciar a la izquierda, y acciones proyectadas (content) a la derecha. Se alinea con la sidebar via --sc-sidebar-width.

1 · Selecciona filas para activar la barra

Cuando [count]="0" la barra no se renderiza. Selecciona alguna fila para verla aparecer abajo (puede que tengas que scrollear).

    @for (row of availableRows; track row.id) {
    • }

Seleccionados: {{ count() }}

2 · Genérico masculino (agentes)

entity.suffixSingular = 'seleccionado' / 'seleccionados' — el default. La barra emite (clear) al click en × → vaciar la selección.

3 · Femenino (etiquetas)

Spanish gender suffix override. La misma selección se muestra como "N etiquetas seleccionadas".

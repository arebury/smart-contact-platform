Component

Datepicker

<sc-datepicker> envuelve PrimeNG <p-datepicker> con el patrón SCDS (label + required + helper + error). Modo popup por defecto, con icono de calendario dentro del input. Soporta [(value)] (signal de Date | null), [(ngModel)] y Reactive Forms.

1 · Basic (popup)

Input con icono de calendario. Al click se abre el panel con el mes actual.

Valor: {{ formatDate(basicValue()) }}

2 · Pre-seleccionado + helper

Estado inicial con hoy, texto de ayuda debajo.

Valor: {{ formatDate(preselected()) }}

3 · Min / Max — solo próximos 30 días

El panel deshabilita las fechas fuera del rango (gris, sin click).

4 · Tamaños (sm / md / lg)

Mismas alturas que <sc-input>.

5 · Estados

Disabled, con "×" para limpiar, y error con mensaje.

6 · Button bar (hoy / limpiar)

Añade dos botones en el footer del panel: "Hoy" salta a hoy, "Limpiar" deja el campo vacío.

7 · Inline (sin popup)

El calendario siempre visible. Útil en wizards o pantallas dedicadas a elegir fecha.

Valor: {{ formatDate(inlineValue()) }}

8 · View=month / View=year

Cuando solo necesitas mes o año (informes, filtros), el panel arranca directamente en esa vista.

9 · [(ngModel)]

Compatible con FormsModule. Cualquier Date que le metas se renderiza con el dateFormat.

Valor: {{ formatDate(ngModelValue()) }}

10 · Reactive Forms + validación

El picker se pinta inválido cuando el FormControl tiene errores Y ha sido touched.

Illustrated Avatar

<sc-illustrated-avatar> renderiza una ilustración SVG hasheada del nombre. Mismo nombre → mismo avatar siempre (cross-pages, cross-reloads, dark mode). Si pasas [photo], la foto subida gana sobre la ilustración. Dos pools: illustrated (24 retratos de personas, default) y abstract (3 patrones para grupos / entidades no-personales).

1 · Pool illustrated (personas)

Hash DJB2 del nombre → bucket en [0, 24). 8 names diferentes → 8 ilustraciones distintas (idealmente).

@for (n of personNames; track n) {
{{ n }}
}

2 · Pool abstract (grupos / entidades)

Para grupos / queues / servicios — asignar "cara humana" a una entidad funcional rompe la metáfora. Solo 3 patrones disponibles; con muchas entidades los avatares se repiten — es intencional.

@for (n of groupNames; track n) {
{{ n }}
}

3 · Sizes (32 / 44 / 64 / 80)

[size] en píxeles. Default 40. El SVG escala con el contenedor, la circunferencia mantiene proporción.

32px
44px (sticky header)
64px (form body)
80px (detail view)

4 · Photo wins over illustration

Si pasas [photo] con un data URL o URL, la foto se renderiza en vez de la ilustración. La ilustración es siempre fallback.

Sin photo → illustration
Con photo → photo wins

5 · Hover zoom

Pasa el ratón por encima — el SVG se escala 1.05× dentro del círculo (efecto "image fills more"). CSS transform, sin segunda imagen.

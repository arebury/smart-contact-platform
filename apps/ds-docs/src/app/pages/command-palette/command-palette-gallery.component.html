Component · Shell-only

Command palette

<sc-command-palette> es el overlay tipo ⌘K / Ctrl+K con búsqueda fuzzy y comandos categorizados (Páginas, Acciones). Se monta UNA VEZ en el shell de la app y escucha el shortcut globalmente. Es el componente más cercano a un "component of context" — no tiene sentido fuera del app shell, por eso esta página es documental (sin demo interactivo).

1 · Cómo se ve

Ábrelo directamente en AED: pulsa ⌘K (Mac) o Ctrl+K (Win/Linux) desde cualquier pantalla de AED. Aparece centrado, con el input de búsqueda autofocado.

Abrir AED en pestaña nueva →

2 · Atajos de teclado

Una vez abierto, el modelo de teclado es el estándar de paletas de comandos (GitHub, Linear, VS Code).

Tecla Acción
⌘ K / Ctrl K Toggle (abre / cierra)
Esc Cierra
↑ ↓ Mueve el cursor entre comandos
↵ Ejecuta el comando seleccionado
Click en backdrop Cierra

3 · Cómo se monta en el shell

Se monta una sola vez en el app.component.html (o en el shell-level template). NO hay que instanciarlo por ruta. La visibilidad la dispara el CommandPaletteService. 

// app.component.ts
import { CommandPaletteComponent } from '@shared/components';

@Component({
  selector: 'sc-app',
  imports: [RouterOutlet, CommandPaletteComponent /* … */],
  template: `
    <router-outlet />
    <sc-command-palette />
  `,
})
export class AppComponent {}

4 · De dónde salen los comandos

CommandPaletteService.commands es un computed derivado de las NAV_SECTIONS del sidebar — cada item navegable de la app se vuelve automáticamente un comando "Páginas". Los comandos "Acciones" (crear agente, abrir atajos, etc.) se inyectan aparte en el service. Cuando añades una ruta nueva al sidebar, aparece sola en la paleta — no hay que tocar nada más. 

export interface PaletteCommand {
  readonly id: string;
  readonly label: string;
  readonly category: 'Páginas' | 'Acciones';
  readonly icon?: NavIconKey;
  readonly keywords?: readonly string[];
  readonly action: () => void;
}

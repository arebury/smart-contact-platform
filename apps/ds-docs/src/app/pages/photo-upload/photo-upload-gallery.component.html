Component

Photo upload

<sc-photo-upload> es el avatar circular subible (formularios Agents + Users). Hover muestra overlay con cámara, file input oculto valida tipo (JPG/PNG/GIF) y tamaño (≤800 KB) y emite el data URL via (photoChange). Si no hay foto y se pasa [name], el placeholder es el IllustratedAvatarComponent hashed desde el nombre (matchea la cell del listado).

1 · Sin foto, con nombre (illustrated fallback)

El placeholder es el portrait ilustrado generado por hash del nombre — el mismo que ves en la cell de la tabla. Click para subir.

2 · Con foto subida

Aparece la foto + link "Eliminar foto" debajo (emite photoChange = null).

3 · Size sm (sin hint ni remove)

44×44, sin row inferior. Pensado para vivir dentro del sticky-form-header (ver sc-sticky-form-header).

4 · Validaciones

Sube un archivo no-imagen o >800 KB para ver los toasts de error.

  • Tipos permitidos: image/jpeg, image/png, image/gif.
  • Tamaño máximo: 800 KB.
  • Errores se muestran en <p-toast> (configurado en este gallery).

Color dot picker

<sc-color-dot-picker> es la fila de círculos seleccionables para elegir color. Two-way bindable via [(value)]. El componente es agnóstico al set — acepta cualquier array de ColorDotOption, así que sirve tanto para la LabelColor palette del DS como para sets ad-hoc.

1 · Paleta LabelColor (caso real AED)

Los 10 colores del sistema de etiquetas. Caso de uso real: AED → Administración → Etiquetas → crear / editar etiqueta.

Seleccionado: {{ labelValue() }}

2 · Paleta corta arbitraria

Demuestra que el componente NO está acoplado a LabelColor: cualquier set { value, label, color } funciona.

Seleccionado: {{ toneValue() }}

Component

Column selector

<sc-column-selector> es el popover de gestión de columnas para tablas: checkbox por columna + drag-and-drop para reordenar. El estado se persiste en localStorage bajo la storageKey. Columnas bloqueadas ( locked: true) se quedan visibles y fijadas arriba — no se pueden ocultar ni mover.

1 · Popover interactivo

Click en el botón "Columnas" → se abre el popover. Drag por el grip para reordenar; checkbox para mostrar/ocultar. Reset vuelve al orden + visibilidad declarados. La preferencia se persiste en localStorage (clave del gallery: ds-docs-column-demo_v1).

Columnas visibles (en orden): [ {{ visibleKeys().join(', ') }} ]

2 · API resumida

Prop Tipo Descripción
columns ColumnDef[] Declaración de las columnas (key, label, locked, defaultVisible).
storageKey string Clave localStorage — incluir sufijo _v<N> para invalidar prefs en bumps.
(orderedVisibleChange) string[] Lista de keys visibles EN ORDEN. Lo que el caller usa para renderizar la tabla.

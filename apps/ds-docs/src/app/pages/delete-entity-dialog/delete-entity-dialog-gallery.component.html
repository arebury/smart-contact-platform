Component

Delete Entity Dialog

<sc-delete-entity-dialog> es el confirm dialog compartido para borrado de entidades (users, groups, agents, templates, labels…). Dos modos: single (typing confirmation con copy-name shortcut) y bulk (lista de chips removibles antes de confirmar). Compuesto sobre <sc-modal> — hereda el shell.

1 · Single mode (typing confirmation)

El usuario debe tipear el nombre EXACTO para activar Eliminar (case-sensitive). El botón "📋 Copiar" es un Fitts shortcut — copia el name al clipboard + toast de confirmación.

2 · Bulk mode (chip pruning)

Cada chip removible con ×. El usuario puede "podar" la selección antes de confirmar. NO auto-cierra si pruna todo — el confirm queda disabled y aparece el botón "Restaurar lista".

3 · Bulk con lista grande (scroll)

La lista hace scroll si los chips no caben. Pattern útil cuando el usuario seleccionó muchos accidentalmente — puede revisar uno a uno.

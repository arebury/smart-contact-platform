Component

Toggle Switch

<sc-toggleswitch> envuelve <p-toggleswitch> con la chrome SC. Switch booleano para opciones tipo activo/inactivo, settings con cambio inmediato. Hereda role="switch", keyboard support (Space/Tab) y form association nativos. Figma SC node 6738:22645.

1 · Basic (on / off)

Estado controlado externamente via [checked]. (checkedChange) emite el nuevo boolean al click o Space.

on: {{ basicOn() }} · off: {{ basicOff() }}

2 · Disabled

El componente se vuelve no-interactivo. Hereda :disabled del input checkbox nativo.

3 · Form row pattern (status)

Patrón canónico en AED: toggle paired con label + helper que actualiza dinámicamente. Usado en user-form, agent-form, group-form para el campo "Estado". Memoria feedback_no_layout_shift: el helper text reserva espacio para evitar CLS al cambiar.

Estado @if (status() === 'active') { Cuenta activa — puede iniciar sesión y recibir llamadas. } @else { Cuenta inactiva — no puede iniciar sesión hasta reactivarse. }

status: {{ status() }}

4 · Permission row (label + info)

Patrón en agent-form sección Permisos: label corta + info button con tooltip + toggle a la derecha. Usado para "Gestionar dispositivos", "Auto-activación", "Grabación", etc.

Gestionar dispositivos
Auto-activación

manage: {{ manageDevices() }} · auto-activate: {{ selfActivate() }}

5 · Theme toggle

Standalone toggle con icono adjacente (sun/moon). Patrón típico en headers de app.

☀️ 🌙

darkMode: {{ darkMode() }} (en producción, conectado a ThemeService que toggle .sc-dark en <html>)

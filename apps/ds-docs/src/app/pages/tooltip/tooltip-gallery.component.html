Component

Tooltip

[pTooltip] es una directiva de PrimeNG, no un componente con slot. Se aplica como atributo a cualquier elemento (típicamente botones icon-only o iconos info). Tokens visuales ajustados a Figma vía sc-preset.ts. Categoría 🟦 Full PrimeNG passthrough.

1 · Basic (hover)

Pasa el ratón por encima del botón para ver el tooltip. Default position = right.

2 · Posiciones (right / left / top / bottom)

tooltipPosition = right (default) / left / top / bottom. PrimeNG calcula la flecha automáticamente.

3 · Botón icon-only (el caso más común)

Patrón típico: botón sin label necesita [aria-label] O [pTooltip] para accesibilidad. PrimeNG aplica el tooltip text como aria-label automáticamente.

4 · Texto largo (max-width 175px)

Figma define tooltip/max/width: 175px. Textos largos hacen wrap automático dentro de ese límite.

5 · En cualquier elemento (icono, texto, etc.)

[pTooltip] se aplica a cualquier elemento HTML. Útil para ayuda contextual en labels, iconos info, etc.

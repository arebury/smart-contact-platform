Component

MultiSelect

<sc-multiselect> envuelve PrimeNG <p-multiselect>. Mismo chrome que <sc-select>, valor es array. Modo comma (texto separado por comas) o chip (pills removibles dentro del input).

1 · Basic (display="comma")

Selección múltiple básica. Los elementos seleccionados aparecen como texto separado por comas. Tras 3 seleccionados, se condensa a "N seleccionados".

Valor: {{ basicValue().join(', ') || '(vacío)' }}

2 · Chips display + objetos con optionValue

Cada selección aparece como pill removible (× para quitar). Valor guardado = solo el código (no el objeto).

Códigos: [{{ channelsValue().join(', ') }}]

3 · Tamaños (sm / md / lg)

Mismas alturas que <sc-select>.

4 · Filter + showClear + selectionLimit

Búsqueda dentro del dropdown, "×" para limpiar todo, y un límite de 3 elementos.

Códigos: [{{ chipsValue().join(', ') }}]

5 · Filled (background slate-50)

Variant del Figma Filled=True (node 6220:7054).

6 · Error

7 · Reactive Forms + validación

Requerido + al menos 1 elemento. Se pinta inválido cuando touched + invalid.

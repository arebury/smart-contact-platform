# .notes/

Carpeta privada. No referenciada en READMEs ni docs públicos.
Vive aquí lo que no es para el equipo ni para el repo público, sino
material crudo para revisar más adelante: journal de sesiones,
postmortems honestos, decisiones casi tomadas, draft de posts que algún
día podrían publicarse.

Estructura:

```
.notes/
├── README.md         ← este archivo
└── journal/          ← sesiones individuales, narrativas de proceso
    └── YYYY-MM-DD-<slug>.md
```

Regla: lo que vive aquí es para ti, no para el repo. Si decides extraer
algo a docs/, blog, conf talk, etc., **copia** — no muevas. El original
en .notes/ se queda para tener la versión sin filtrar.
